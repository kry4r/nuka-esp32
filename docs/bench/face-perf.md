# FE2-04 表情面调度与性能记录

2026-10-24。实现和 SDL 观察已完成，设备性能验收未完成。本记录不把模拟器的帧循环频率换算成设备帧率或 CPU 占用。

## 实现

- 两只眼睛只用 LVGL 基础对象：实色圆角矩形、单层低亮外沿、黑色眼睑、线段螺旋；没有位图、模糊或全屏透明动画。
- 状态改变按 ANIM_BASE（180 ms）从当前几何参数过渡到目标；空闲眨眼间隔为 3–7 s，视线缓慢漂移并偶尔轻跳。
- 活跃状态、眨眼和过渡的定时器周期为 16 ms；其余亮屏空闲为 100 ms。周期是调度配置，并非测得帧率。
- 表情面隐藏、离开主页、进入 L1、熄屏或电量低于 10% 时暂停动画定时器；低电仍允许每秒静态状态更新。熄屏不调用表情渲染。
- 只在 lvgl 任务调用 LVGL。语音状态、字幕和幅度通过 home_app.h 的 UI 接口更新；真实音量包络接入属于 FW2-06。

## SDL 观察

Windows / MSVC Debug，SDL_VIDEODRIVER=dummy，480×480。每次运行 180 个模拟器循环，循环尾部有 16 ms 延时，源数据为仓库假数据。下表的“渲染次数”是表情回调次数，不是面板帧数。

| 场景 | 渲染次数 | 退出时动画定时器 | 屏幕 |
|---|---:|---|---|
| 表情面空闲、电量 80% | 43 | 运行 | 亮 |
| 表情面、电量 5% | 4 | 暂停 | 亮 |
| 表情面后按 PWR 熄屏 | 14 | 暂停 | 熄灭 |
| 表情面后 Key3 短按切回时钟 | 19 | 暂停 | 亮 |
| 恢复菜单中按 Key3 | 0 | 暂停 | 亮 |

空闲随机动作会让重复运行的回调次数变化。完整原始截图、逐状态 GIF 和捕获记录在忽略目录 build/ui-v2-plan/；[14 状态静态图](ui-v2-faces.png)和[录屏拼图](ui-v2-face-motion.gif)可用于视觉审阅。录屏以每四个模拟器循环截取一帧制作，GIF 调色与帧时长量化均影响回放，不能据此验收 NFR-2。

## 待实机测量

| 验收项 | 状态 | 缺少的证据 |
|---|---|---|
| 活跃局部动画 ≥55 fps | 跳过 | 设备性能 HUD 与实际动画时序 |
| 亮屏空闲 CPU ≤5% | 跳过 | FreeRTOS 运行时统计 |
| 触摸第一帧 ≤50 ms | 跳过 | 设备 GPIO/逻辑分析仪或高速录像 |
| 普通联网内部空闲 ≥100 KB | 跳过 | 遍历新页面后的真实 diag.info |
| 会话内部空闲 ≥64 KB | 跳过 | 真实音频会话，归 FW2-05 / FW2-06 |
| 熄屏、低电功耗 | 跳过 | USB 电流表及电池回路测量 |
| 设备视觉评审 | 跳过 | 实机照片和维护者反馈 |

这些缺口使 FE2-04 仍处于“实现与模拟器通过，实机验收待完成”，不能据此关闭 M9。
