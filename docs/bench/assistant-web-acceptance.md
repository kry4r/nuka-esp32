# C2-03 / BE2-10 非音频与 Web 验收记录

日期：2026-10-24。所有数据均为本地合成数据；没有请求真实模型、CPA、CPAMP、ASR、TTS 或搜索服务。

## 已通过

| 项目 | 方法与结果 |
|---|---|
| 远程权限（T1） | 在 Access 关闭时创建应用，再切换到启用配置；仅 Bearer、缺失或无效 JWT、过期或缺 exp 均拒绝。有效签名 + issuer + audience + exp + admin 会话允许读取；写入缺 CSRF 拒绝。Hooks、审批、配对仍公网 404。 |
| 工具闸门（T9） | 未注册工具拒绝；敏感工具无确认、拒绝、超时、取消均不执行。允许后排队的取消在副作用之前处理。停止流会取消待确认轮，不写入记忆。 |
| 完整档案与有限上下文 | 保存 24 个完整轮，档案保留全部 48 条用户/助手消息；上下文只取最近 20 个完整轮，未完成轮不回填。 |
| 重启与恢复 | SQLite 在线备份和附件同锁快照；离线 integrity_check、每个文件 SHA-256 校验后恢复到新目录，重新创建 Hub 后消息、记忆和文件仍在。修复 Windows 暴露的备份连接未关闭问题。 |
| 关闭记录 | 关闭后新轮只有有界内存上下文，永久档案不新增；原记录仍可管理。 |
| 删除 | 活动会话先取消并等待，SSE 以 cancelled done 结束；延后检查无写回。会话消息与来源记忆同事务删除，附件独立保留。 |
| 列表和导出 | 游标两页无重复；JSONL 时间顺序导出 48 行，仅公开字段，不含 Pi 内部 payload；导出为 attachment。 |
| 设备隔离 | 另一已注册设备读取会话或附件均 404；普通模式不接受未注册的 dev_id。demo 使用既有 nuka_example 合成设备。 |
| 上传边界 | 路径文件名、无效 UTF-8、.nukavault、NVB1 内容和分块累计超额均拒绝。磁盘仅使用 opaque ID，下载 attachment + nosniff；不解包或执行。 |
| 表单 | 真实浏览器加载配置 schema，渲染所有已冻结集成字段；错误预算保存返回 400 并显示在助手组内。有效保存保留已有注释与数组顺序。高级 TOML 使用相同并发与备份流程。 |
| 文字助手 | 离线假引擎经 HTTP SSE 增量回复；会话 ID、永久记录与分页显示正常。中文/英文切换不丢失字段值。 |
| 响应宽度 | 桌面 1365×900、手机 390×844，页面未出现横向溢出。截图保存在忽略的 build/review/，名称以 BE2-06-config、BE2-07-assistant 开头。 |

最终自动化全套：105 通过，耗时 66.06 秒（一个原有告警表达式 warning），包含适配器轨道新增的 8 个 T3 fixture。T1 / T9 组合为 50 通过；Pi 预检移到工作线程后，T9 再次 11 通过。T6 为 82 个 schema / 171 个 payload / 0 问题；零个人值为 696 个文本文件 / 0 问题；SPDX 为 344 个源文件 / 0 问题；ruff check 与 format check 通过。
