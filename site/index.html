NUKA · ESP32-S3

安装 nuka-esp32
Install your device system

适用于 Waveshare ESP32-S3-Touch-AMOLED-2.16。使用桌面版 Chrome 或 Edge，通过 USB 数据线连接。
Use desktop Chrome or Edge with a USB data cable.

1 · 完整备份 / Back up first

首次刷入前，先退出所有串口工具，用 esptool 读取完整 16 MiB 原厂 Flash，并确认文件大小。备份留在本机。
Close serial tools, read all 16 MiB, and verify the backup file size. Keep the backup locally.

uvx --from esptool==4.11.0 esptool.py --chip esp32s3 --port <PORT> read_flash 0 0x1000000 factory-16m.bin

若设备当前使用 NukaVault，也请先导出加密备份。进入下载模式：按住 BOOT，重启，再松开 BOOT。
Export your encrypted NukaVault backup first. To enter download mode, hold BOOT, reset, then release BOOT.

完整操作指南 / Full instructions

2 · 刷入 / Install

仅写入固件与资源对应区域，保留 NVS 和 Vault 分区。首次安装写入资源 bank 0；后续更新请使用 OTA。
The installer writes firmware and assets while preserving NVS and Vault partitions. First install uses assets bank 0; use OTA for later updates.

请使用支持 Web Serial 的桌面版 Chrome 或 Edge。 / Use desktop Chrome or Edge.

请通过 HTTPS 或 localhost 打开。 / Open this page via HTTPS or localhost.

确认备份后可连接设备。 / Confirm your backup to enable installation.

3 · 配网与配对 / Connect & pair

刷入成功后，关闭刷机窗口以释放串口，运行以下命令，在本机交互输入 Wi-Fi 凭据，并核对设备上的配对码。
Close the flasher to release the port, then enter Wi-Fi credentials locally and confirm the pairing code on the device.

nuka init
nuka hub
# 在另一个终端 / In another terminal:
nuka pair

也可使用设备的 SoftAP 配网页。 / The device also supports SoftAP provisioning.
